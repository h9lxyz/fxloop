# FXLoop

An MCP server plus an in-JVM agent that gives coding agents eyes (screenshots, scene graph, "why" tools), ears (logs, UI exceptions) and hands (click, type, set property) on a running JavaFX app, with a fast edit loop: CSS/FXML live reload, Java HotSwap, restart with replay.

* Start with the [README quickstart](https://github.com/h9lxyz/fxloop#quickstart).
* See what the agent gets in the [MCP server overview](mcp.md), and the UI/UX workflows built on it in [Agent skills](skills.md).
* Tune behaviour in [Configuration](configuration.md); see every tool in the [Tools reference](tools.md).
* Know the edges: [Limitations](limitations.md), [Security](security.md), [Troubleshooting](troubleshooting.md).
* Run it in CI: [CI templates](ci/README.md).
